AAN — GOOGLE SHEETS ORDER STORAGE SETUP

This version is compatible with GitHub Pages.

WHAT IT DOES
- Customer confirms an order.
- The order is immediately shown in Order History.
- The order is submitted to a Google Sheet.
- WhatsApp order sharing continues as before.
- When Order History opens, the site can load the latest 50 central orders from Google Sheets.
- Local browser history is retained as a fallback.

IMPORTANT PRIVACY NOTE
The central history endpoint in this simple version returns recent orders to the website. Because it is designed as a public web app for a static GitHub Pages site, do not store sensitive personal information beyond what you actually need for fulfilment.

SETUP
1. Create a new Google Sheet in Google Drive.
2. Open Extensions -> Apps Script.
3. Open GoogleAppsScript_Code.gs from this folder and copy all its code into Code.gs.
4. Save.
5. Click Deploy -> New deployment.
6. Select "Web app".
7. Execute as: Me.
8. Who has access: Anyone.
9. Deploy and authorize it.
10. Copy the Web app URL ending in /exec.
11. Open index.html.
12. Find:
      const AAN_ORDERS_ENDPOINT = '';
13. Replace it with:
      const AAN_ORDERS_ENDPOINT = 'YOUR_WEB_APP_EXEC_URL';
14. Upload the updated index.html to your GitHub repository.

TEST
- Place one test order.
- Check the Google Sheet: a new "Orders" tab should contain the order.
- Refresh the website and open Order History.

If you later want proper customer-specific history, admin-only order access, payment status, or order status updates, use a real backend/database with authentication rather than exposing a public history endpoint.
