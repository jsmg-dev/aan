AAN GOOGLE SHEETS + CUSTOMER HISTORY + ADMIN SETUP

1. Create a Google Sheet in Google Drive.
2. Extensions -> Apps Script.
3. Replace Code.gs with GoogleAppsScript_Code.gs from this package.
4. Change ADMIN_PASSWORD in Code.gs to a strong private password.
5. Deploy -> New deployment -> Web app.
   Execute as: Me
   Who has access: Anyone
6. Copy the deployed /exec URL.
7. Open index.html and set:
   const AAN_ORDERS_ENDPOINT = 'YOUR_WEB_APP_EXEC_URL';
8. Open admin.html and set the same URL in AAN_ORDERS_ENDPOINT.
9. Push index.html and admin.html to GitHub Pages.

CUSTOMER HISTORY:
- Customer enters the SAME phone + email used at checkout.
- Google Sheets returns only matching orders.
- Orders are also cached locally for faster display.
- This is identity matching, not OTP authentication. For high-security customer accounts, add OTP/login.

ADMIN HISTORY:
- admin.html shows ALL orders.
- Admin password is checked by Google Apps Script, not stored in the website.
- Do not put the admin password inside index.html.
